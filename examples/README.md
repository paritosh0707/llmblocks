## ⚡ **Quick Start**

```bash
# 1. Setup (one time)
git clone https://github.com/paritosh0707/llmblocks.git
cd llmblocks
uv sync
export GOOGLE_API_KEY="your-api-key"

# 2. Try the simplest example (just 3 lines!)
python examples/minimal/01_hello_world.py

# 3. Build a chatbot (just 5 lines!)
python examples/minimal/02_smart_chatbot.py

# 4. See real-time streaming (just 4 lines!)
python examples/minimal/03_streaming_ai.py
```

- **Maximum functionality** - Enterprise features built-in
- **Developer joy** - Simple, intuitive, and powerful
